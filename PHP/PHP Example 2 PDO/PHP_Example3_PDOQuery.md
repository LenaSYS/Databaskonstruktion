### Overview

This example contains shows how to show data in a table from the foreach statement.


### Introduction

If a query has no parameters (most often a whole table) the query function is the most efficient function for querying the database.


Data is generated by reading from the returned data row by row (===PHP_Example3_PDOQuery.php,10,12,rows 10-12===). We display the returned data for each row with Print_R. In later examples we show how to build tables using queries.
