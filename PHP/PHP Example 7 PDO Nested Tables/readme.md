### Overview

This example contains shows how to connect to a database and call a procedure using PDO.

### Query

Using pdo is very simple, a new pdo object is created. We send the credentials to pdo using a string.

```php
		$pdo = new PDO('mysql:dbname=a00leifo;host=localhost', 'myusername', 'mypassword');
		$pdo->setAttribute( PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION );
```

By using the query statement, any database operation can be executed. The foreach iterates over the results if more than one row is returned (===PHP_Example2_PDO.php,15,15,row 15===).

```php
$pdo->query( 'SELECT * FROM CUSTOMER;' );
```

If a query has no parameters (most often a whole table) the query function is the most efficient function for querying the database.

Data is generated by reading from the returned data row by row. We display the returned data for each row with Print_R. In later examples we show how to build tables using queries.

```php
foreach($pdo->query( 'SELECT * FROM CUSTOMER;' ) as $row){
    	print_r($row);			
}
```

### Procedure Call

The application calls the procedure GETAVGCOST. The result is shown in the same way as the query. Print_r is very useful if we do not know the naming of each of the columns.

```php
foreach($pdo->query( 'CALL GETAVGCOST();' ) as $row){
    print_r($row);
}
```
In essence, calling a procedure (a so call select procedure) that returns data as a table, is almost exactly the same as querying the database directly.

### Generate table

If we want to create an ordinary table we can generate the table tag using the foreach

```php
// Read all customers to a table
foreach($pdo->query( 'SELECT * FROM CUSTOMER;' ) as $row){
    echo "<tr>";
    echo "<td>".$row['CUSTNO']."</td>";
    echo "<td>".$row['SSN']."</td>";
    echo "<td>".$row['NAME']."</td>";
    echo "<td>".$row['REGDATE']."</td>";
    echo "</tr>";	
}
```
